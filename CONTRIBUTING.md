# Guia de contribucion

La guia oficial de contribucion se encuentra en `docs/contribucion.md`.

## Atajo rapido

1. Crea rama: `feature/*`, `fix/*`, `docs/*` o `chore/*`.
2. Ejecuta validacion:

```bash
npm run lint
```

3. Abre PR con contexto, cambios y evidencia visual si aplica.

Para el detalle completo revisa `docs/contribucion.md`.
